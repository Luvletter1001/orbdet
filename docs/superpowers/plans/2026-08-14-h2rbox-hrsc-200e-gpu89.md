# H2RBox HRSC 200E GPU 8/9 Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Launch and verify a clean pure-H2RBox HRSC2016 200-epoch baseline on physical GPUs 8 and 9.

**Architecture:** Add isolated formal and smoke MMEngine configs that inherit the already validated pure-H2RBox HRSC configuration. Add fixed two-rank launchers, validate the merged configuration, pass a bounded DDP smoke run, then launch the formal run in a named tmux session and record live evidence.

**Tech Stack:** Python 3.10, PyTorch 1.12.1, MMEngine 0.10.3, MMDetection 3.3.0, MMCV 2.2.0, MMRotate, NCCL/DDP, Bash, tmux.

---

The Orbdet directory is not a Git repository, so commit steps are replaced by
fresh file and runtime verification. Existing artifacts must not be overwritten.
