# SCQO HRSC LE90 校正说明

本目录是对 `exp_scqo_plan_a_hrsc_audit_20260817` 的角度标签语义校正。
旧目录完整保留，仅用于追溯；其中预测框与 GT 框未先统一到 LE90，因而把
`(w, h, theta)` 与 `(h, w, theta + pi/2)` 的等价表示误记为约 90° 误差。
旧目录的哈希和行数仍然有效，但其角度误差标签及由此得到的 Gate B 结论不应作为论文证据。

校正只作用于诊断日志：旋转 IoU 匹配仍使用原始框；预测、匹配、证据特征、
模型与训练路径均未改变。记录角度前，预测框与 GT 框的克隆分别通过
`RotatedBoxes.regularize_boxes('le90')` 规范化，源张量保持不变。

## 解释边界

`INSUFFICIENT` 表示 HRSC validation 在这两个冻结 checkpoint 下没有至少 15 个
真实大角度错误，无法计算预注册的二分类 AUROC；它不是 SCQO 表征假设的反证。
因此不应据此放弃当前方案，也不应启动 E4。后续 H2/H3 应在保持 LE90 语义的
前提下，转到具有足够自然角度难例的数据集，或使用预注册且不改变 GT 语义的
受控扰动协议进行检验。

本次只读取冻结 checkpoint 和 HRSC validation，没有训练、调参或测试集评估。
