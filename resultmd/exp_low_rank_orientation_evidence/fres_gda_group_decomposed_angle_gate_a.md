## 2. 群论框架

### 2.1 高斯对称空间表示

旋转矩形 (w,h,θ) ↔ 二维高斯协方差 Σ = R(θ)diag(w²/12, h²/12)R(θ)ᵀ。Sym⁺(2) 的 KAK 分解：

```
Σ = e^t · (cosh a·I + sinh a·[[cos ψ, sin ψ],[sin ψ, −cos ψ]]),  ψ = 2θ
```

- t = 对数尺度，a = 各向异性（½ log 特征值比 = log(w/h)），ψ = 双角（u₂ 谐波载体）；
- 旋转不变量 (t,a) 与轨道坐标 ψ 显式分离；
- O(2) 以共轭作用：旋转 φ → ψ+2φ，反射 → −ψ，处处光滑可微。

**编码群商**：(w,h,θ)、(h,w,θ+π/2)、(w,h,θ+π) 给出同一个 Σ——BCGE（Liu et al., IEEE TCYB 2025）/GauCho（CVPR 2025）/结构张量编码（Bou et al. 2024）的"边界连续性"本质是这一商映射的连续性。同一数学对象，我们从代码层核实了 BCGE 的实现（`gussian_coder.py`：回归协方差三元素，特征分解解码）。

### 2.2 HBox 监督的可见范围（核心定理式观察）

HBox 包络写成 Σ 的函数：

```
W² = 12Σ₁₁ + 12√detΣ·|sin2θ|
H² = 12Σ₂₂ + 12√detΣ·|sin2θ|
```

右边只含 V₄ 不变量。因此：

- **可见**：轨道坐标 |θ|（由 cos2θ 坐标化，[0,π/2) 单调）；
- **不可见**：恰好一个离散比特 sign(θ)（腔室比特）；
- **近似失明区**：aspect→1 时监督稳定子从 V₄ 近似长到 D₄（包络获得近似 π/2 周期）——1.3 节的翻转浓缩正是它的经验表现。

现行 snap loss 是 V₄ 不变量环的特手工实现；GDA 把它系统化。

### 2.3 与 BCGE 的差异定位

BCGE 是全监督（GT OBB → GT 高斯直接回归）。GDA 把协方差表示搬进 HBox 弱监督：监督信号只能写在中 2.2 的不变量环上，腔室比特只能来自跨视图等变一致性。**BCGE 没有也不需要处理"监督看不见腔室"的问题；这个问题只在弱监督下存在。**

## 3. GDA 设计（训练侧，待授权）

1. **表示**：检测头输出 (t, a, ψ) 替代/并联 (w,h,θ)；
2. **包络一致性损失**：三视图一致性在不变量环上计算（`envelope_consistency_loss` 已实现并通过解析测试），规范等价预测零惩罚；
3. **腔室比特的离散一致性**：跨视图等变分类，目标由配对视图 detach 生成（防自强化）；
4. **内蕴门控**：腔室损失的逐实例权重 = detach 的预测各向异性 â——SCQO 外置稳定子门控 (π₂,π₄,π_reject) 从表示几何中内蕴涌现，无需校准器；
5. **评测**：解码仅在算指标时发生（le90），另报商空间口径列（近各向同性实例按 S¹/C₄ 计分），不污染标准 mAP。

预期声明（预注册）：不承诺 P50；主指标为 aspect≥2 实例 e2 口径 P90 与 >15° 占比改善、flip 率在 [1.1,1.3) 带下降、AP50 非劣（−0.2pt 内）。

## 4. Gate-A：解析验证（已通过）

模块 `mmrotate/models/utils/gda_symmetric_space.py`，测试 `tests/test_gda_gate_a.py`，提交 `2d04ced`。12 条测试各钉住一个数学声明：

| 测试 | 钉住的声明 |
|---|---|
| A1 | (t,a,ψ)↔Σ 往返忠实（SPD、模 2π 意义下 ψ 闭合） |
| A2 | (w,h,θ)→Σ→le90 解码往返，模编码群 |

| A6 | 包络公式 = 解析式 = 暴力角点法（三方一致） |

## 5. Gate-B：只读实证验证（预注册）

### B1 门控统计量有效性（已测，通过）

假设：â = log(aspect) 单独即可预测翻转。结果（39,301 实例，GT aspect 为代理；匹配 IoU 中位 0.96，预测 aspect 近似误差不改变量级）：

| 指标 | 数值 |
|---|---|
| AUROC(−â → flip) | **0.8882** |
| aspect<1.05 | 覆盖 11.9%，捕获翻转 51.5% |
| aspect<1.10 | 覆盖 18.9%，捕获 76.7% |
| aspect<1.20 | 覆盖 27.4%，捕获 92.1% |
| aspect<1.30 | 覆盖 37.8%，捕获 96.9% |

判定：AUROC ≥ 0.85 且 aspect<1.2 工作点捕获 ≥90% → **通过**。

### B2 跨种子腔室稳定性（已测，按字面 inconclusive，细化读数见下）

假设：若近方形实例的腔室是规范自由度（不可学习），则两个独立种子在同一实例上的腔室选择应接近随机；若可学习，则跨种子一致。

- 数据：E0（seed3407，匹配 41,754 实例）与 E0′（seed42，`orbdet_v0_2_dota1_grouped_ss_e0prime_seed42_gpu89_seed3407/epoch_12.pth`，匹配 42,272 实例，缓存 manifest sha256 `3987ff7a…`，52,974 行/3,968 图，比 seed3407 少 105 图、原因未查，交集 join 使其无害；两侧 holdout manifest 哈希一致）在相同 grouped holdout 上分别前向，独立匹配同一 GT（IoU≥0.5），双侧都匹配的交集 **36,881 实例**；
- 统计：逐桶（GT aspect，与 B1 同口径代理）跨种子 |wrap180(θ_A−θ_B)|>45° 的腔室不一致率。

**实测主表**：

| aspect 桶 | n | 跨种子不一致 >45° | xseed \|Δθ\| P50/P90 | flipA% / flipB% | 双翻转% |
|---|---|---|---|---|---|
| [1.0,1.1) | 5,934 | **16.55%** | 0.91° / 90.00° | 22.14 / 20.61 | 12.89 |
| [1.1,1.3) | 6,713 | 3.90% | 0.94° / 4.45° | 4.86 / 6.54 | 3.43 |
| [1.3,2.0) | 16,682 | 0.33% | 0.78° / 2.14° | 0.23 / 0.28 | 0.09 |
| [2.0,4.0) | 7,237 | 0.00% | 0.67° / 1.78° | 0 / 0 | 0 |
| [4.0,∞) | 315 | 0.00% | 0.69° / 2.52° | 0 / 0 | 0 |

- χ²(aspect<1.1 vs 池化 aspect≥2，n=7,552，不一致 0.00%) = **1347.9** ≫ 6.63 → 显著性条款满足；aspect≥2 ≤2% 条款满足；但 aspect<1.1 桶 16.55% 介于 10% 与 30% 两条预注册线之间 → **按字面判定 INCONCLUSIVE**，如实记录，不向任一侧裁剪。

**细化分解（不一致从哪里来）**：逐实例记录 flipA（种子 A 相对 GT 翻转）、flipB 后，不一致率 ≈ P(flipA XOR flipB)（推算 16.97% vs 实测 16.55%，几乎全部不一致由腔室翻转解释）。三个读数：

1. **翻转聚在同一批实例上**：双翻转 12.89% ≫ 独立基准 pA·pB = 4.6%；P(B翻转|A翻转) = 58% vs 边际 20.6%（[1.1,1.3) 桶同构：70.6% vs 6.5%）。即"哪些实例的腔室不可辨识"是**实例属性**（C₄ 近似对称的外观），不是种子运气——支持商空间计分（这些实例的 GT 腔室编码本身是规范任选）。
2. **腔室部分可学**：实测不一致 16.55% ≪ 独立随机基准 pA+pB−2pApB = 33.6%。两个独立种子显著比随机更常选同一腔室——监督信号对腔室并非完全失明——因此硬阈值式门控（aspect 一刀切停梯度）会丢弃真实信号，**被 B2 排除**。
3. **连续坐标处处稳定**：非翻转实例的跨种子 |Δθ| 各桶 P50 = 0.66–0.94°、P90 ≤ 3.05°，包括近方形桶——连续部分无规范自由度问题，GDA 只需处理那一个比特。

**对第 3 节设计的修正**：预注册叙事"腔室=规范 ⇒ 门控"过于二元。实测图景是：会翻的实例集合高度确定（â 可预测，B1），翻向哪个腔室有约 1/6 的种子间摇摆。设计第 4 条（detach â 软权重门控）与此图景**精确匹配、维持不变**；硬阈值变体被排除。

遗留：预注册时承诺用预测 (w,h) 复核分桶，但现有缓存未存预测宽高（仅 pred_angle/pred_score），重采缓存后补做；GT aspect 代理的可靠性已由匹配质量（IoU 中位 0.96）间接支撑。

## 7. 风险与诚实边界

- 收益性质是**损失卫生**（移除 37.8% 带噪信号）+ **诚实计分**，不是角度精度跃迁；P50 无可争取空间（连续部分 1.89°）。
- 真实可修翻转（aspect≥1.3）仅占 0.14%，不允许拿它许诺 AP 收益。
- GT aspect 作为 â 代理依赖匹配质量（IoU 中位 0.96）；B2 原计划的预测 (w,h) 复核因缓存缺预测宽高字段未做，列为遗留（见 §5-B2 末尾）。
- 新颖性边界：协方差回归（BCGE/GauCho）、高斯损失（GWD/KLD）、结构张量编码（Bou 2024）、HBox 一致性（H2RBox/-v2）均已发表；可站住的组合是"**对称空间表示 × HBox 弱监督 × 内蕴稳定子门控 × 商空间评测**"四元组。按 SCQO 文档纪律，系统查重前不使用"首次"。
