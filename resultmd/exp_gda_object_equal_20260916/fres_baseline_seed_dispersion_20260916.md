# Base vs C_equal 三种子结果：均值不显著，跨 seed 离散度显著收窄

## 2. 均值读法：不显著，且几乎全部来自 seed42

| 指标 | 配对差均值 | 样本 SD | SE | t |
| --- | ---: | ---: | ---: | ---: |
| AP50 | +0.1670 | 1.0391 | 0.600 | 0.28 |
| AP75 | +1.7493 | 1.8655 | 1.077 | 1.62 |
| mean | +0.9582 | 1.4458 | 0.835 | 1.15 |

三点观察：

1. **效应集中在单一 seed。** seed42 贡献 Δmean +2.63pp，另两个 seed 分别只有 +0.16 / +0.09pp，AP50 上后两者为负（−0.27 / −0.58）。把 seed42 去掉，剩余两 seed 的 Δmean 均值仅 +0.12pp。
2. **Δmean +0.96pp 低于既有噪声底线 1.70pp**，配对差 SD（1.45pp）大于均值本身。
3. seed42 的 **base** 是三个 base 里最差的（base AP75 25.66 vs 另两个 30.92 / 31.50，低约 5pp）。也就是说"提升"更可能来自 base 侧的一次低走，而不是 C 侧的系统性抬升 —— C 的 AP75 三 seed 为 29.57 / 31.50 / 32.26，与 3407/2026 的 base 基本同高。

**因此不能表述为"C_equal 相对 base 带来约 +1pp 增益"。** 该结论在 n=3 下不被支持。

## 3. 但跨 seed 离散度收窄是三个指标一致的方向

这是本轮读数据时新发现的、比均值更稳的信号：

| 指标 | base 跨 seed SD | C 跨 seed SD | 收窄倍数 |
| --- | ---: | ---: | ---: |
| AP50 | 1.0210 pp | 0.2868 pp | 3.56x |
| AP75 | 3.2130 pp | 1.3885 pp | 2.31x |
| mean | 2.1079 pp | 0.6625 pp | 3.18x |

即：**C 的收益主要体现为把学生 seed 间波动压小，而不是把均值抬高。** C 的 AP75 三 seed 全部落在 29.6–32.3 的窄带内，而 base 从 25.7 铺到 31.5。

这与"种子里有一支 base 低走"的观察是同一件事的两种表述，因此**两者不是互相独立的证据**，不能叠加计权。它只是一个待检验假设：等权 KD 可能起方差稳定作用。

n=3 下 SD 本身估计极不可靠（SD 的相对标准误约 40%+），本节的数字不应作为任何结论的证据强度，只能用来**确定下一轮该看什么**。

## 4. 对 Phase-2 门禁的影响

在跑的 `object_equal` 两臂（GPU8/9，epoch 8/12，ETA ≈ 4h48m，约 15:50 前后收工）测的是 `object_mean`，与之配对的 base 就是上表这一支。

含义：
- 只比 `object_equal` 与 base 的**均值差**，会掉进和上面同一个陷阱：base 侧的 seed42 低走会让 `object_equal` 看起来同样"约 +1pp"，而这个数不能被解读为机制有效。
- 建议在门禁读表时**同时读出跨 seed SD**。若 `object_mean` 在均值上与 `point_mean` 相近，但 SD 收窄没有进一步变好，则两个 reduction 在当前证据下不可区分，差异落在噪声内。
- `object_mean` 的设计意图（每个对象等质量）本身就不指向"抬高均值"；把它按均值增益评判，等于用错的判据。
